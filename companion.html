SDA Sabbath companion

One small program for the PC that runs the service. It links that PC to the other devices on the church Wi‑Fi or network, with no internet needed:

  • OBS on another computer: the lower third and the slides follow SDA Sabbath.
  • Phones as a remote, a TV or second PC as the screen, and stage screens.
  • Videos from the PC’s Videos folder, and exact PowerPoint conversion (with LibreOffice).

Set it up on Windows

  1. Download the Windows program above on the PC that runs the service.
  2. Double‑click selah-windows-x64.exe. Windows may say it “protected your PC”: click More info → Run anyway (the program is not signed by a company).
  3. When Windows asks about network access, tick Private networks and click Allow. Without this, other computers cannot reach it.
  4. SDA Sabbath opens in your browser at http://localhost:7777. Use SDA Sabbath from this tab during the service (not the website) and keep it open.
  5. Optional: to get a Start‑menu and desktop shortcut, run it once with --install (PowerShell: .\selah-windows-x64.exe --install).

Connect OBS on the second computer

  1. Make sure both computers are on the same Wi‑Fi or network.
  2. In SDA Sabbath (the localhost:7777 tab) open Tools → Stream. The box “OBS on another computer” shows two addresses with this PC’s network address in them.
  3. Click Copy lower third address. Send it to the OBS computer (e‑mail, WhatsApp, or type it — it looks like http://192.168.1.20:7777/obs.html?via=lan&mode=lower).
  4. In OBS: Sources → + → Browser, paste it as the URL, set Width 1920, Height 1080, press OK, and drag it above the camera.
  5. Show a Bible verse in SDA Sabbath: the words appear in OBS. For full‑screen slides, add the Presentation address the same way in its own scene.

OBS says “waiting for the media desk”? The OBS link works, but SDA Sabbath is not open at http://localhost:7777 on the companion PC. Open it there (not the website) and keep it open. OBS shows nothing at all? Open the same address in a browser on the OBS computer; if it does not load, allow the companion through Windows Firewall on private networks.

Raspberry Pi or Linux

Download the Linux file, then in a terminal: chmod +x selah-linux-* and run it. Open http://localhost:7777.
